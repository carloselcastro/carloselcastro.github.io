# ODETE.SYS

Browser-local robot voice and singing synthesizer by Carlos Castro. Open `index.html` through an HTTP server or deploy this folder to GitHub Pages.

No build, Python backend, API key, or external audio service is required. All voice synthesis and MIDI import/export run in the browser. Compositions are saved in this browser on the current website origin; compositions on localhost are separate from those on the published website.

The singing voice is experimental. Daisy Bell is the demonstration song (Harry Dacre, 1892); the app is named ODETE.SYS.

References: [Praat source-filter synthesis](https://www.fon.hum.uva.nl/praat/manual/Source-filter_synthesis.html), [CMU dictionary](https://github.com/cmusphinx/cmudict), [Daisy Bell transcription](https://abcnotation.com/tunePage?a=back.numachi.com%3A8000%2Fdtrad%2Fabc_dtrad.tar.gz%2Fabc_dtrad%2FDAISYBEL%2F0000), [Standard MIDI Files](https://midi.org/standard-midi-files).
